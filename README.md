# SkillSwitch - Switch Careers, Level Up

A modern career transition platform that helps professionals analyze their skills, explore new career paths, and access personalized learning resources.

## 🚀 Features

- **Career Path Explorer**: Browse curated career paths with detailed skill requirements
- **Skills Analyzer**: Analyze your current skills and identify gaps
- **Learning Paths**: Personalized learning recommendations for career transitions
- **Success Stories**: Read inspiring stories from career switchers
- **Pricing Plans**: Flexible subscription options for different needs
- **Interactive Testimonials**: See what users are saying about SkillSwitch
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile

## 🛠️ Tech Stack

- **Frontend Framework**: React 18.3.1
- **Build Tool**: Vite 6.0.3
- **Routing**: React Router DOM 6.28.0
- **Styling**: Tailwind CSS 3.4.16
- **Animations**: Framer Motion 11.15.0
- **Icons**: Lucide React 0.468.0
- **PostCSS**: 8.4.49

## 📋 Prerequisites

- Node.js (v14 or higher)
- npm or yarn

## 🚀 Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/YOUR-USERNAME/skillswitch.git
cd skillswitch
```

2. Install dependencies:
```bash
npm install
```

### Development

Run the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:5174/`

### Build for Production

Create an optimized production build:
```bash
npm run build
```

### Preview Production Build

Preview the production build locally:
```bash
npm run preview
```

## 📁 Key Components

- **Navbar**: Navigation header with links to main sections
- **HeroSection**: Landing page hero with call-to-action
- **FeaturedPaths**: Showcase of popular career paths
- **PathCard**: Individual career path card component
- **Testimonials**: User testimonials section
- **PricingCard**: Subscription pricing display
- **Footer**: Site footer with links and information

## 📄 Pages

- **Home** (`/`): Landing page
- **Paths** (`/paths`): Browse all career paths
- **Path Detail** (`/paths/:id`): Detailed view of a specific path
- **Analyzer** (`/analyzer`): Skills analysis tool
- **Stories** (`/stories`): Success stories from users
- **Pricing** (`/pricing`): Subscription plans
- **About** (`/about`): About SkillSwitch
- **Contact** (`/contact`): Contact form
- **Login** (`/login`): User login
- **Signup** (`/signup`): User registration
